# Heimildarkóði Mac-útgáfunnar

Þetta er afrit af kóða Mulehead 1.5.6 (Electron). Hann á EKKI að þýðast hér —
hann er bara til að fletta í hegðun: hvaða reglur voru notaðar og af hverju.

- `m3u.js`, `epg.js`, `playlists.js`, `store.js`, `sports.js`, `webserver.js`, `vodproxy.js` → `Downloads/mulehead/lib/`
- `main.js`, `preload.js` → rót Mac-útgáfunnar
- `renderer/` → UI, spilari og sync
- `pack.js` → bygging Mac-appsins
- `Hvernig-a-ad-setja-upp.txt` → uppsetningarleiðbeiningar sem frændinn fékk

Skýringar og forskriftir eru í `../../docs/HANDOFF.md`.
